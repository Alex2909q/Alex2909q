# Звукарик — Android-застосунок для тренування вимови звуків (3–8 років)

Щоденний домашній тренажер вимови українською, побудований за логопедичною методикою
(звук → склади → слова → фрази → речення → вірші → розрізнення → мовлення) і сучасними доказовими
принципами (інтенсивність «потроху, але щодня», моторне навчання, слуховий самоконтроль, батьки як тренери).

> Застосунок **не ставить звуки й не замінює логопеда** — він допомагає робити вдома те, що фахівець «задав»,
> і підказує, коли варто звернутися до нього.

## Як встановити APK

1. Відкрийте вкладку **Actions** репозиторію → останній запуск **Android APK** → секція *Artifacts* →
   завантажте `zvukaryk-release-apk` (≈2,3 МБ) або `zvukaryk-debug-apk` (≈21 МБ, з логами).
2. Перекиньте файл на телефон, дозвольте встановлення з невідомих джерел, встановіть.
3. Перший запуск: онбординг для дорослого (ім'я, вік, короткий скринінг, перевірка звуків за картинками,
   вибір 1–3 цільових звуків). Далі дитина працює з екрана «Грати».
4. Для озвучення українською потрібен **Google Синтезатор мовлення** з українським голосом
   (Налаштування → Спеціальні можливості → Синтез мовлення → завантажити мову). Без нього зразки читає дорослий.

Вимоги: Android 8.0+ (API 26). Дозволи: мікрофон (запис/прослуховування, вимір гучності), камера (режим «дзеркало»),
інтернет (лише для помічника Claude, коли введено API-ключ). Без реклами й аналітики; прогрес і записи — на пристрої.

## Голос і помічник Claude

**Голосовий супровід (офлайн, системний TTS).** Застосунок сам говорить з дитиною: вітає на головному екрані,
промовляє завдання кожного кроку з прикладами («Тепер слова зі звуком С. Наприклад: сонце, собака, сова»),
озвучує зразки слів і речень, коментує спроби, оголошує завершення. Кнопка 🔊 у шапці кроку повторює завдання.
Вимикається у «Для батьків → Налаштування».

**Звукарик-помічник на Claude (Anthropic API, tool use).** Агент із трьома інструментами —
`get_child_progress` (профіль і прогрес), `get_sound_material` (матеріал звука), `speak_to_child` (сказати дитині вголос) —
працює на офіційному Anthropic Java SDK (`com.anthropic:anthropic-java`). Що він робить:

| Де | Що робить Claude |
|---|---|
| Екран звука | «Поясни звук інакше» — персональна підказка з образом, озвучена; «Розкажи казку» і «Загадай загадки» лише зі слів цього звука |
| Заняття, крок «Як сказати звук» | Альтернативне пояснення голосом, якщо стандартна підказка не спрацювала |
| Заняття, рівень «Речення» і вище | Крок «Казка від Звукарика»: 5–6 коротких речень із цільовими словами, дитина повторює речення за реченням, дорослий оцінює |
| Підсумок заняття | Озвучена конкретна похвала дитині + 1–2 поради дорослому на завтра |
| «Для батьків → Помічник» | Чат для батьків: Claude читає прогрес через інструменти й відповідає за методикою; завжди каже, коли потрібен логопед |

Технічно: модель за замовчуванням `claude-opus-5-5` (вибір Sonnet 5.5 / Haiku 5.5 у налаштуваннях), системний промпт кешується
(`cache_control`, 1 година), `effort: low` для реплік дитині та `medium` для батьків, серверний fallback при відмові
класифікатора безпеки (`fallbacks: "default"`), ручний цикл tool use з поверненням усіх `tool_result` одним повідомленням,
типізована обробка помилок (401/403/429/400/мережа). Аудіо ніколи не надсилається — лише текст.

**Як увімкнути:** «Для батьків» → «Налаштування» → «Помічник Claude» → увімкнути, вставити ключ із
console.anthropic.com (API Keys → Create Key), натиснути «Перевірити зв'язок» — Звукарик відповість голосом.
Важливо: підписка Claude Pro/Max на claude.ai **не дає** доступу до API; потрібен акаунт на платформі розробника
з оплатою за використання (одне заняття з казкою — орієнтовно кілька центів на Opus 5.5).

## Що вміє (v0.1)

| Блок | Що робить | На чому ґрунтується |
|---|---|---|
| Онбординг і скринінг | Вік, зрозумілість мовлення, «червоні прапорці», перевірка 9 звуків за картинками, рекомендація цільових звуків за віковою нормою | Норми появи звуків (свистячі 3–4, шиплячі 4–5, Л/Р 5–6), Рібцун; Shepherd 2026, McLeod & Crowe 2018 |
| Планувальник заняття | 7–10 хв: розминка (2–3 вправи) → «як сказати звук» → ізольований звук → практика за рівнем → «Вухо-детектив» → підсумок; мета 40–70 продуктивних спроб | Williams 2012 (≥50 спроб), Maas 2008 (блочна → випадкова практика, рідший зворотний зв'язок) |
| 8 рівнів автоматизації | Ізольований → склади (прямі/обернені/між голосними) → слова (3 позиції) → словосполучення → речення й чистомовки → скоромовки й вірші → диференціація → вільне мовлення | Van Riper; Шеремет/Соботович/Рібцун; LogoClub |
| Правила просування | Наступний рівень автоматично: ≥80 % чітких спроб, ≥20 спроб, ≥2 заняття; 6 занять без прогресу → порада до логопеда | Критерій 80–90 %; Sugden 2018 |
| Анімований «ротик» | Положення губ, зубів і язика для кожного звука й кожної вправи гімнастики (Canvas, без ассетів) | Speech Tutor / MIO як референси |
| Розминка (Веселий Язичок) | 19 вправ з таймером утримання та лічильником повторів; коротка й вимикається | НУМО/МОН; чесно позначена як розминка (McCauley 2009, Cochrane 2015) |
| Ізольований звук | Ігри «Насос», «Комарик», «Змійка», «Моторчик»: мікрофон вимірює тривалість звука, дорослий оцінює якість | Біологічний зворотний зв'язок «бачу свій голос» |
| Картки слів | ~130 слів з емодзі-картинками (читати не потрібно), озвучення зразка, **«Запиши себе → послухай себе»**, оцінка дорослого ✅ / 🟡 / 🔁 | Слуховий самоконтроль; «без червоних хрестиків» |
| Вухо-детектив | Почуй слово — обери картинку (мінімальні пари с–ш, з–ж, л–р, ш–ж, ч–ш…) | Фонематичний слух, Rvachew; минимальні пари |
| «Перевір мене» | Експериментальне розпізнавання мовлення (uk-UA), подається лише як підказка, вимкнено за замовчуванням | Чесність: WER дитячого мовлення у 2–5 разів вищий |
| Дзеркало | Фронтальна камера поруч з анімованим зразком вправи | MIO |
| Мотивація | Наліпки за заняття (не за спробу), серія днів, «усе зроблено» ритуал | Рекомендації з дизайну для дітей |
| Для батьків | Батьківський замок, прогрес і історія, червоні прапорці, налаштування, **звіт для логопеда** (share), методика й застереження | Sugden 2016/2020; Pritchard 2024 |

Контент: 9 звуків (С, З, Ц, Ш, Ж, Ч, Щ, Л, Р), 100+ складів, ~130 слів із картинками, 60+ речень і чистомовок,
30 скоромовок, вірші, 40+ пар для розрізнення, 19 вправ артикуляційної гімнастики, 3 дихальні гри.

## Структура проєкту

```
zvukaryk-android/
├── app/src/main/java/ua/zvukaryk/app/
│   ├── data/model/Models.kt          # Звук, рівні, вправи, прогрес (serializable)
│   ├── data/content/                 # Логопедичний контент: Sounds*.kt, ArticulationExercises.kt
│   ├── data/progress/                # DataStore-репозиторій стану (JSON)
│   ├── domain/SessionPlanner.kt      # Планувальник заняття + MasteryRules (просування рівнями)
│   ├── ai/                           # ClaudeAgent (Anthropic SDK, tool use), AgentTools, VoiceCoach (голосовий супровід)
│   ├── speech/                       # TTS, запис/відтворення з амплітудою, SpeechRecognizer
│   ├── ui/components/                # MouthAnimation (Canvas), великі кнопки, оцінювання, батьківський замок
│   └── ui/screens/                   # Onboarding, Home, Session, Sounds, Parent, Mirror, Stickers
├── app/src/test/                     # Unit-тести: цілісність контенту, планувальник, правила просування
└── docs/RESEARCH.md                  # Дослідження: доказова база + українська методика, з джерелами
```

Стек: Kotlin 2.1, Jetpack Compose (Material 3), Navigation, DataStore, kotlinx.serialization, CameraX, Anthropic Java SDK 3.3, AGP 8.9, Gradle 8.14.

## Збірка локально

```bash
cd zvukaryk-android
./gradlew test assembleDebug assembleRelease
# APK: app/build/outputs/apk/debug/app-debug.apk, app/build/outputs/apk/release/app-release.apk
```

CI (`.github/workflows/android.yml`) на кожен push збирає обидва APK і запускає тести; тег `v*` публікує GitHub Release з APK.
Для підпису релізу власним ключем додайте secrets `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`
(без них release підписується debug-ключем і все одно встановлюється).

## Відомі обмеження та бекліг

- **Не перевірено на реальному пристрої** (збірка в хмарі без емулятора). Перший запуск на телефоні може виявити
  дрібні огріхи верстки — перевірте онбординг, заняття зі звуком С і дзеркало.
- Озвучення залежить від системного TTS (потрібен український голос Google); плануємо записи логопеда
  (ізольовані приголосні без призвука «-е») і, як опцію, хмарний синтез з природнішим дитячим голосом.
- Казки й поради Claude генеруються на льоту; варто додати кеш казок на пристрої та ліміт запитів на день.
- Картинки — емодзі; наступний крок — ілюстрації та відео артикуляції (фронт + профіль, сповільнено).
- Розширити базу до ≥90 слів і ≥20 чистомовок на звук (норма методик), додати м'які [л'], [р'], [дз], [дж].
- Нагадування про заняття (WorkManager), кілька профілів дітей, експорт звіту у PDF.
- Валідація розпізнавання мовлення на власному дитячому корпусі перед тим, як показувати будь-яку оцінку «вийшло».
- Розповсюдження через Google Play вимагає політики Families (вікова група, відсутність реклами, декларація мікрофона).
